What "Human review" does

When ON, the conversion pauses after each file the AI translates. The node turns amber on the graph and shows up under Awaiting review in the sidebar.

You can then:
  • Click the amber node → modal opens with COBOL on the left and editable Java on the right
  • Approve as-is — write the AI's output to disk
  • Save edits & approve — write your edited version to disk
  • Reject — mark the file as failed
Optional glob filter:

If you set a pattern like **/critical/*.cbl, only files matching it will pause for review. Everything else flows through automatically.

Bulk actions:

When multiple files queue up, use Approve all / Reject all in the sidebar to clear the queue at once.
