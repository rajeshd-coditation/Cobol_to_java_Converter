# Vendored: OpenSourceCobol4j

This directory is a vendored snapshot of the OpenSourceCobol4j project.

- Upstream: https://github.com/opensourcecobol/opensourcecobol4j
- License: see `COPYING` and `COPYING.LIB` in this directory
- Purpose: provides the `cobj` compiler and `libcobj` Java runtime used by the
  COBOL → Java conversion pipeline in `tools/web-ui/`.

The `carddemo-app/` subdirectory is a vendored copy of the AWS Mainframe
Modernization CardDemo sample, used as test fixture input for the converter.
Upstream: https://github.com/aws-samples/aws-mainframe-modernization-carddemo

Do not edit files under this directory unless you intend to maintain a fork;
prefer pulling fixes from upstream.
